Bootstrap Container Queries

Version 4 (Bootstrap 6) · Version 3 (Bootstrap 5)

What is it?

Bootstrap's responsive classes react to the viewport. This library adds classes that react to the width of a parent container instead, using CSS container queries. A component behaves the same whether it is in a sidebar or in a full-width page.

Install

npm i bootstrap@next bootstrap-container-queries@next

With CSS, load the file after Bootstrap 6 (it uses Bootstrap's cascade layers): 

<link href="bootstrap.min.css" rel="stylesheet" />
<link href="bootstrap-container-queries.min.css" rel="stylesheet" />

With Sass (Dart Sass 1.103+, @import is not supported): 

@use "bootstrap-container-queries/scss/bootstrap-container-queries";

Usage

Add .bcq to the parent (an alias of Bootstrap's .contains-inline), then use classes prefixed with @breakpoint:: 

<div class="bcq">
  <div class="d-none @md:d-block">Visible when the container is at least md</div>
</div>

<div class="bcq row">
  <div class="@sm:col-6 @lg:col-3">...</div>
</div>

Without prefix the class is plain Bootstrap and applies at every width. The container must have a width of its own: it cannot size itself from its content.

Reference

Breakpoints: sm 576px, md 768px, lg 1024px, xl 1280px, 2xl 1536px (the Bootstrap $breakpoints).

Feature Classes Example
Grid @{bp}:col-{1-12} @md:col-4
Display @{bp}:d-{value} @lg:d-none
Flex direction @{bp}:flex-{value} @lg:flex-column-reverse
Text align @{bp}:text-{start|center|end} @md:text-end
Float @{bp}:float-{start|end} @sm:float-end
Margin, padding @{bp}:m{sides}-{n}, @{bp}:p{sides}-{n} @xl:mt-5, @md:px-3

Utilities are generated from Bootstrap's own $utilities, so values (and spacing scale) match Bootstrap 6.

Customize

@use "bootstrap-container-queries/scss/bootstrap-container-queries" with (
  $container-queries-breakpoints: (xs: 0, sm: 30em, md: 48em),
  $container-queries-utilities: ("display", "gap")
);

Good to know

  • .bcq creates a stacking context, which can affect z-index and Z-axis transforms of descendants.
  • Browsers: Chrome and Edge 130+, Firefox 132+, Safari 18+ (same as Bootstrap 6).
  • Coming from 3.x? See the migration table.
